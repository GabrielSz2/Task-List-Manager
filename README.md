# Lista de Tarefas

Este é um projeto simples de uma lista de tarefas desenvolvido em Java. O objetivo do projeto é permitir que os usuários criem, visualizem, editem e excluam tarefas, ajudando-os a gerenciar suas atividades diárias de forma eficiente.

## Funcionalidades

- **Adicionar Tarefas**: Permite ao usuário adicionar uma nova tarefa à lista.
- **Listar Tarefas**: Exibe todas as tarefas adicionadas, mostrando seus detalhes.
- **Editar Tarefas**: Permite ao usuário modificar os detalhes de uma tarefa existente.
- **Excluir Tarefas**: Remove uma tarefa da lista.
- **Marcar Tarefas como Concluídas**: Permite ao usuário marcar uma tarefa como concluída.

## Tecnologias Utilizadas

- **Java**: Linguagem de programação utilizada para o desenvolvimento do projeto.
- **Java Collections**: Utilizado para armazenar e manipular a lista de tarefas.
- **Eclipse/IntelliJ**: IDEs recomendadas para o desenvolvimento e teste do projeto.
